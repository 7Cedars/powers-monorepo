# Powers Protocol — Documentation

The documentation site for the Powers Protocol, built with [Astro Starlight](https://starlight.astro.build). Deployed at [powers-docs.vercel.app](https://powers-docs.vercel.app/welcome).

---

## Commands

```bash
cd documentation
pnpm install
pnpm dev      # dev server at localhost:4321
pnpm build    # build to ./dist/
pnpm preview  # preview the production build locally
```

---

## Content structure

All documentation lives in `src/content/docs/`. Each `.mdx` file maps to a route by filename.

```
src/content/docs/
├── welcome.mdx
├── use-cases.mdx
├── for-developers/
│   ├── powers.mdx              # Powers.sol architecture
│   ├── mandate.mdx             # Mandate contract guide
│   ├── creating-a-mandate.mdx  # How to write a new mandate
│   ├── deploy-powers-script.mdx
│   ├── litepaper.mdx
│   └── architecture.mdx
├── for-organisations/
│   ├── deploy-powers.mdx       # Deploying an organisation
│   ├── best-practices.mdx
│   └── compliance.mdx
├── example-organisations/      # One page per example org (including /design-org output)
├── mandates/
│   ├── electoral/
│   ├── executive/
│   ├── integrations/
│   └── reform/
└── development.mdx
```

---

## Adding a page

1. Create a `.mdx` file in the appropriate `src/content/docs/` subdirectory.
2. Add frontmatter at the top:

```mdx
---
title: Your Page Title
description: One-line description shown in search and social previews.
---
```

3. The page is live at `/<filename>` (or `/<folder>/<filename>`) on the next `pnpm dev` reload.

---

## Adding an organisation page

Organisation specs generated by the [`/design-org`](../governance-rag/README.md) skill are written to `src/content/docs/example-organisations/`. Each file follows the same MDX template and appears automatically in the sidebar under **Example Organisations**.

---

## Deployment

The site deploys automatically to Vercel on push to `main`. No manual steps needed.
